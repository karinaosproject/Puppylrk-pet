Como baixar o APK de CI

Workflow APK debugDisparado em push ou manualmente.
Artifact meu-pet-apkPublicado pelo passo upload-artifact.
Release assinadaNão confundir o APK debug com uma versão pronta para distribuição pública.
Atenção de segurança: o arquivo de chave de debug codificado em Base64 está no repositório público. Base64 não é criptografia. Trate essa chave como exposta; gere outra chave para debug e mantenha a chave de release fora do Git.
